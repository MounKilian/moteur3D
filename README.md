# Plateformer 2D 👾

Welcome to my 3D project !

# Prerequisite ⏪

Somes knowledges in this field : 

- The use of C++ 
- The use of OpenGl
- The use of Git and for the code management

# Installation 🔧

1. Clone the repository.
```bash
  git clone https://github.com/MounKilian/moteur3D.git
```
2. Reach in the repository.
```bash
  cd .\cpp3D\
```

# Start 🧑‍💻

1. Launch the game by pressing CTRL + F5 or by clicking the green Run triangle.

# Features 🔨

You can import .obj and .mtl with their texture on .png

You can test Shadow with PointLight only.
You can test SpotLight and DirLight (comment) but PointLight must be activated
You can test only 2 spotlight, 1 dir light and 1 point light

You can move with arrow and up with Z and down with S
